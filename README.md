# 🍜 Food Order App

เว็บแอปสั่งอาหาร — เพิ่มชื่อเมนู ระบุราคา และสรุปจำนวน/ราคารวมอัตโนมัติ

## ฟีเจอร์
- เพิ่มเมนูอาหาร พร้อมราคาและจำนวน
- ปรับจำนวน +/- และลบรายการได้
- สรุปจำนวนเมนู จำนวนจาน ราคาเฉลี่ย และยอดรวม
- บันทึกข้อมูลใน localStorage (ปิดเว็บแล้วข้อมูลไม่หาย)
- Responsive รองรับมือถือ แท็บเล็ต และเดสก์ท็อป

## เทคโนโลยี
HTML5 / CSS3 (Grid + Flexbox) / Vanilla JavaScript — ไม่มี dependency

## วิธีใช้
เปิดไฟล์ `index.html` ด้วยเบราว์เซอร์ได้เลย
